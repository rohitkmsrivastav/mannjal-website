Five steps, alternating sides to show the handoffs. Mannjal does the work in the middle (intake, rules, docs, routing) but never makes the credit call — that stays in the lender lane. Reinforces the neutral-orchestration position without saying it as a claim.
Underneath all five steps

Reconciliation and audit run the whole length of the file

Reconciliation isn't a final step — it's continuous. Each lender's position updates as the loan moves, and asset classification stays in sync on both sides if a borrower misses a payment.

Audit trail

Every action, API call, and document event is timestamped, attributed, and exportable on demand. This is the spine the diagram sits on.

The brief calls for recon + audit "maintained throughout." Pulling them out as a band under the diagram says that better than a sixth step would — they run in parallel, not after.
