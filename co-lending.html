What Mannjal handles

From program setup to partner-level MIS.

01
Program setup

Configure once, clone for every partner

Define eligibility rules, risk split, blended rate, product parameters and compliance thresholds. When you add a new co-lending partner, the same configuration applies.

02
File orchestration

Eligibility and policy checks run up front

Bureau and KYC checks route through the lender's own providers. Deviations are flagged before the file reaches the credit desk. Files reach the credit committee ready to review.

03
Reconciliation

Escrow, MIS and RBI returns from the same data

Disbursement and recovery reconciled across partnerships. Partner-level MIS generated from the same loan-level data that drives the escrow routing. One source of truth.
